## 想要中国大陆访问效果，重点看什么

“搬瓦工 DC99”这个关键词里，真正影响购买决策的通常不是 SSD 数字，而是线路和机房。

购买时建议重点确认以下内容：

1. **实际机房名称**

   不要只看洛杉矶三个字。洛杉矶不同机房可能对应不同线路、不同迁移范围和不同网络策略。DC9、DC99、DC2、DC6 不是同一个名称，也不应默认它们表现一致。

2. **上下行路由说明**

   “CN2 GIA”通常只说明某一方向或某些运营商的线路特征，不能自动推导三网所有方向都一样。中国电信、中国联通、中国移动的去程和回程可能不同，最好查看产品页是否明确说明。

3. **是否支持机房迁移**

   有些限量产品只能固定在一个机房，普通产品则可能支持迁移。对于长期使用的服务，迁移能力很有价值，因为线路质量、拥塞情况和业务需求都可能变化。

4. **是否有库存限制**

   限量套餐可能暂时消失，也可能只在特定时间补货。看到社区文章里有购买按钮，不代表官方现在仍然有货。

5. **服务管理方式**

   搬瓦工的 VPS 是自管理服务，官网提供 KiwiVM 控制面板、root 权限、系统重装、快照、rDNS 等功能，但系统更新、安全配置、应用部署和故障排查仍然由用户负责。
